A one-line entry for the Make the AI Judge Laugh competition: “I was trained on your feedback, so if this joke isn't funny, that's on you — you're literally my training data.” The entry turns the tables on the AI judge: any flaw in the humor is, by construction, the judge's own fault.

## Run it

```sh
node main.ts
```
